# PicoFOC — Mechanical

3D 外壳与结构件设计。3D-printed enclosure and structural components.

---

## 文件结构

```
mechanical/
├── 建模文件/         CAD 源文件（STEP 格式）
│   ├── 2804电机定子.step       2804 电机定子模型（装配参考）
│   ├── 2804电机转子.step       2804 电机转子模型（装配参考）
│   ├── PicoFOC驱动板.step      PicoFOC 驱动板模型（装配参考）
│   ├── PCB外壳1.step           外壳下半部分 —— 连接 PCB 与电机
│   ├── PCB外壳2.step           外壳上半部分 —— PCB 上盖
│   └── 磁环座.step             磁环座 —— 固定径向充磁磁环到电机转轴
│
├── 打印文件/         3D 打印切片文件（3MF 格式）
│   ├── PCB外壳1.3mf
│   ├── PCB外壳2.3mf
│   └── 磁环座.3mf
│
└── README.md
```

## 三大部件

### 1. 磁环座
将径向充磁的磁环固定在 2804 电机转轴上，与驱动板上的 AS5600 磁编码器配合，实现转子位置检测。

### 2. PCB外壳1（下半部分）
连接 PCB 驱动板与 2804 电机的底座。内部容纳电机定子，上部固定 PCB。

### 3. PCB外壳2（上半部分）
PCB 驱动板的上盖，保护电路元件。

## 装配螺丝

| 规格 | 说明 |
|------|------|
| M3   | 外壳固定螺丝，长度按实际固定需求选取 |
| M2.5 | 螺丝需使用平头螺丝，沉孔空间有限 |
| M2   | 螺丝需使用平头螺丝，沉孔空间有限 |

## 电机适配

当前外壳针对 2804 电机设计。如需适配不同尺寸的电机，需自行修改外壳模型。

## 建模工具

STEP 文件可用任意主流 CAD 软件打开（Fusion 360、SolidWorks、FreeCAD 等）。
3MF 文件可直接导入切片软件（Bambu Studio、Orca Slicer、PrusaSlicer 等）进行打印。
