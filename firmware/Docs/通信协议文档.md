## 2. 传输层帧格式

### 2.1 CAN 帧

CAN 直接发送 8 字节 payload，无额外帧头。

- **控制帧**（主机 → 电机）：`CAN ID = 0x000 + motor_id`
- **状态帧**（电机 → 主机）：`CAN ID = 0x100 + motor_id`

当前配置：`motor_id = 1`，故：

| 方向 | CAN ID | 说明 |
|------|--------|------|
| 主机 → 电机 | `0x001` | 控制指令 |
| 电机 → 主机 | `0x101` | 状态回传 |

### 2.2 UART 帧

```
 字节偏移: [0]    [1]    [2~9]         [10~11]
         ┌──────┬──────┬──────────────────┬────────────┐
         │ 0xAA │ 0x08 │ 8 bytes payload  │ CRC16-CCITT │
         │ 帧头  │ 长度  │（与 CAN 相同）  │  小端       │
         └──────┴──────┴──────────────────┴────────────┘
```

- **帧头（SOF）**：`0xAA`，用于接收状态机同步
- **长度字段**：固定 `0x08`，表示后续 8 字节 payload
- **CRC16-CCITT**：多项式 `0x1021`，初始值 `0xFFFF`，对 SOF + LEN + payload 共 10 字节计算，小端存放
- UART 状态帧发送频率：100 Hz（CAN 为 1 kHz，UART 做 10 分频）

## 3. 统一 8 字节 Payload 定义

CAN 和 UART 的 8 字节 payload **格式完全一致**，共用同一套编解码代码（`motor_msg.c` 中的 `DecodeCommand` 和 `TxStatus`）。

### 3.1 RX 控制帧（主机 → 电机）

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| [0] | mode | uint8 | 运行模式 |
| [1~4] | target | float32 LE | 目标值（不同模式下含义不同） |
| [5~6] | Kp | uint16 LE | 比例增益编码值 |
| [7] | Kd/Ki | uint8 | 微分/积分增益编码值 |

#### 3.1.1 运行模式（mode）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | STANDBY | 待机，关断驱动芯片，PWM 停止 |
| 1 | TORQUE | 力矩模式（预留，未实现） |
| 2 | SPEED | 速度模式（使用 SpdPID_Ext） |
| 3 | POSITION | 位置模式（串级：位置 PD → 速度 PI） |
| 4 | CALIBRATE | 电角度自校准 |

#### 3.1.2 目标值（target）

target 为 IEEE 754 单精度浮点数，小端字节序。

| 模式 | 单位 | 物理含义 | 代码内换算 |
|------|------|---------|-----------|
| SPEED | rad/s | 目标机械角速度 | `rpm = target × 9.5493` |
| POSITION | rad | 目标机械角度 | `deg = target × 57.2958` |
| CALIBRATE | — | 忽略 | — |

**注意：target 无边界校验**，任意 float 值都会被接受。上位机需自行保证数值合理。

#### 3.1.3 比例增益（Kp）

| 项目 | 值 |
|------|-----|
| 原始类型 | uint16 LE |
| 解码公式 | `kp = raw × 0.00015259` |
| raw 范围 | 0 ~ 65535 |
| kp 范围 | **0 ~ 10.0** |
| 分辨率 | 0.00015259 |
| 编码公式 | `raw = kp / 0.00015259`（四舍五入） |

解码系数推导：`10.0 / 65535 ≈ 0.00015259`

#### 3.1.4 微分/积分增益（Kd/Ki）

| 项目 | 值 |
|------|-----|
| 原始类型 | uint8 |
| 解码公式 | `kd = raw × 0.00392157`（同时写入 pos_kd 和 spd_ki） |
| raw 范围 | 0 ~ 255 |
| kd/ki 范围 | **0 ~ 1.0** |
| 分辨率 | 0.00392157（1/255） |
| 编码公式 | `raw = kd / 0.00392157`（四舍五入） |

解码系数推导：`1.0 / 255 ≈ 0.00392157`

**⚠️ 注意：Kd 和 Ki 共用一个字节。** 调位置环 Kd 的同时会改变速度环 Ki。无法同时独立设置两个值。

### 3.2 TX 状态帧（电机 → 主机）

| 字节 | 字段 | 编码公式 | 类型 |
|------|------|---------|------|
| [0~1] | 位置 | `raw = pos_rad × 834.4` → int16 LE |
| [2~3] | 速度 | `raw = speed_rads × 655.34` → int16 LE |
| [4~5] | Vq | `raw = vq × 819.175` → int16 LE |
| [6~7] | 保留 | 始终填 0 | — |

编码公式为 `raw = value × scale`，然后截断为 int16（-32768 ~ 32767）。

#### 3.2.1 位置反馈

| 项目 | 值 |
|------|-----|
| 编码公式 | `raw = pos_rad × 834.4` |
| 原始范围 | -32768 ~ 32767 |
| 可编码 pos_rad | **-39.27 ~ +39.27 rad**（≈ -2250° ~ +2250°，约 6.25 圈） |
| 分辨率 | 1 / 834.4 ≈ **0.0012 rad ≈ 0.069°** |
| 设计依据 | `32767 / (12.5 × π) ≈ 834.4` |

#### 3.2.2 速度反馈

| 项目 | 值 |
|------|-----|
| 编码公式 | `raw = speed_rads × 131.07` |
| 原始范围 | -32768 ~ 32767 |
| 可编码 speed_rads | **-250.0 ~ +250.0 rad/s** |
| 可编码 rpm | **-2387 ~ +2387 rpm** |
| 分辨率 | 1 / 131.07 ≈ **0.0076 rad/s ≈ 0.073 rpm** |
| 设计依据 | `32767 / 250 ≈ 131.07` |

**⚠️ 注意：量程已扩。** 2026-07-25 从 `655.34` 改为 `131.07`，可编码范围从 ±477.5 rpm 扩至 ±2387 rpm。分辨率降至 0.073 rpm，对控制调试无影响。

#### 3.2.3 Vq 反馈

| 项目 | 值 |
|------|-----|
| 编码公式 | `raw = vq × 819.175` |
| 原始范围 | -32768 ~ 32767 |
| 可编码 vq | **-40.0 ~ +40.0 V** |
| 分辨率 | 1 / 819.175 ≈ **0.00122 V** |
| 设计依据 | `32767 / 40 ≈ 819.175` |

实际母线电压 12V，Vq 被 `FOC_Output` 限幅在 ±12V，远在编码量程内，**无饱和风险**。

## 4. VOFA+ 调试通道

独立于自定义协议之上，与自定义协议共用同一根 UART 线，**互不干扰**。

**帧格式：**

```
[N × float (4N bytes)] [0x00, 0x00, 0x80, 0x7f]
 通道数据              VOFA+ just-float 帧尾
```

- 帧尾 `0x00,0x00,0x80,0x7f` 是 IEEE 754 浮点数 `1.1755e-38`（接近零的非规范化数），VOFA+ 用它识别帧结束
- 自定义协议以 `0xAA` 开头，VOFA+ 看到 `0xAA` 当无效浮点数忽略
- 自定义上位机看到 `0xAA` 开头的帧才处理，看到 VOFA 帧 CRC 校验不通过就丢弃
- 发送频率：**100 Hz**（受 `UARTProto_SendVOFA` 内部 10ms 间隔限速）

**通道映射（main.c VOFA_SendDebug）：**

| 通道 | 变量 | 单位 |
|------|------|------|
| ch0 | `Motor.mech_angle` | deg（机械角度） |
| ch1 | `Motor.target_angle` | deg（目标角度） |
| ch2 | `Motor.speed` | rpm（实际转速） |
| ch3 | `Motor.target_speed` | rpm（目标转速） |
| ch4 | `Motor.Uq` | V（交轴电压） |
| ch5 | `MotorMsg_GetLastMode()` | 整数（运行模式） |
| ch6 | `MotorMsg_GetLastTarget()` | rad/rpm/Nm |
| ch7 | 0 | —（保留） |

## 5. 指令示例

### 5.1 CAN 命令（8 字节 payload，CAN ID = 0x001）

| 命令 | Payload（HEX） | 说明 |
|------|---------------|------|
| 待机 | `00 00 00 00 00 00 00 00` | mode=0 |
| 速度 5 rad/s | `02 00 00 A0 40 42 00 01` | kp=0.01, ki=0.004 |
| 速度 10 rad/s | `02 00 00 20 41 42 00 01` | kp=0.01, ki=0.004 |
| 速度 50 rad/s | `02 00 00 48 42 42 00 01` | kp=0.01, ki=0.004 |
| 位置 0° | `03 00 00 00 00 00 80 00` | kp=5.0, kd=0 |
| 位置 45° | `03 00 00 DB 0F 00 80 00` | kp=5.0, kd=0 |
| 校准 | `04 00 00 00 00 00 80 00` | — |

### 5.2 UART 命令（完整帧，含帧头 + CRC）

| 命令 | 完整帧（HEX） |
|------|--------------|

| 速度 10 rad/s | `AA 08 02 00 00 20 41 42 00 01 1A B3` |
| 位置 0° | `AA 08 03 00 00 00 00 00 80 00 D3 52` |
